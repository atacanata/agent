# ADR-001: Stack Profile Selection

## Context
Bu repo, Ubuntu VDS üzerinde çalışan ve doküman→kod→test→runbook disiplinini uygulayan bir AI_TEAM şablon/runner projesidir. Stack seçimi, Stage A içinde netleştirilmelidir.

## Decision
`stack_profile` olarak **`api_fastapi_py`** seçildi.

## Rationale
- Şablon/runner odağında hızlı prototipleme ve otomasyon ihtiyaçları için Python uygundur.
- FastAPI, API tabanlı iskelet için düşük bariyerli ve hızlı kurulum sağlar.
- Repo içi CI ve script akışı Python ortamı ile doğal uyum sağlar.

## Tradeoffs
- Alternatiflere (ör. Node/TS) göre tip güvenliği ve ekosistem tercihleri değişebilir.
- Daha yüksek performans gerektiren senaryolarda başka profiller avantaj sağlayabilir.

## Why Now
Stage A’da temel yönelimlerin netleşmesi, Stage B (UX+OpenAPI) ve Stage C (Code+CI+Runbook) çıktılarının tutarlı ilerlemesi için gereklidir.
